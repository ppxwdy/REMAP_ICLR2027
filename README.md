# REMAP_NIPS2026

The code of REMAP for the ICLR 2027 submission.

To run the code, you need to change the location to the data file in the exp2_remap.py and run the exp2_remap.py directly, the file should be in UAI data format.

In the output, only the actual loss means the energy value corresponding to the problem, other loss refers to the NN trainning loss.
